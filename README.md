## 三网优化具体优化了什么，新加坡的运营商表现差异

“三网优化”指的是把三家运营商的流量分别送上各自的精品线路：电信走 CN2、联通走 AS9929、移动走 CMI/CMIN2，再按源 IP 自动选择回程。CN2 比普通 163 骨干拥塞少，AS9929 是联通的高端国际线路，CMIN2 是移动较新的国际网络。新加坡机房不少，但同时把三条回程都做优化的供应商确实不多。

不过“三网都优化”不等于“三网表现一样好”。2025 年 12 月的一篇公开测评（测试机型包括 SIN.Pulse.Mini）给出的运营商排序是这样的：

- **移动**：新加坡 > 日本 ≈ 香港，原文说法是“新加坡移动彻底起飞”
- **电信**：香港 ≈ 日本 > 新加坡，三地都稳，新加坡排最后但仍可用
- **联通**：香港 > 日本 > 新加坡，并明确写了“联通新加坡上行断流比较严重”

这个结论对选型的影响很直接。移动线路用户是新加坡节点最舒服的群体；电信用户能用，但如果业务对延迟敏感，香港或日本更合适；联通用户选新加坡要谨慎，尤其是有大量上传需求的场景（直播推流、大文件回传），上行断流会很难受。

官方文档只写“三网优化”，没有对新加坡的联通表现做任何提示。这类信息只能靠第三方实测补上。
